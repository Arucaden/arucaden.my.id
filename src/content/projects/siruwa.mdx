> **SIRUWA** is an information system for room and space management, built to help local RT/RW communities coordinate shared facilities.

### Overview

The project focused on making reservation and availability clearer for residents and administrators, with a responsive interface built on Laravel and Alpine.js.

### My Role

I contributed to frontend implementation and UI polish using Tailwind and Alpine, coordinating with the team on forms, listing views, and basic admin workflows.
