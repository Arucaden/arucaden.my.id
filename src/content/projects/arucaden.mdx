> **arucaden.my.id** is my personal portfolio website, built to showcase my projects, skills, and artwork while providing a lightning-fast browsing experience.

---

### Executive Summary & Role

As the **Frontend Engineer & UI/UX Designer**, I built this platform as an evolution from my previous slide-based portfolio. The goal was to create a fast, content-driven static website while injecting JavaScript reactivity only where strictly needed using Astro Islands and Svelte 5 Runes.

---

### Key Features

- **Astro Content Collections:** Type-safe markdown-driven architecture for projects and devlog articles.
- **Interactive Component Islands:** Interactive overlays, filters, and dynamic cards rendered via lightweight Svelte 5 components.
- **Custom Aesthetic & Animations:** Bespoke visual styling, glitch effects, and CRT scanline themes powered by CSS transitions and vanilla JavaScript.

---

### The Problem & The Solution

**The Problem:**
- Typical developer portfolios often rely on heavy client-side single-page application (SPA) frameworks that bloat JavaScript bundle sizes and degrade first-load performance.
- Off-the-shelf templates frequently lack individuality and fail to showcase creative design identity.
- Complex animation libraries often introduce runtime overhead.

**The Solution:**
- Adopted **Astro** for zero-JS-by-default server-side HTML generation, paired with **Svelte 5** for surgical reactivity.
- Used **UnoCSS** for on-demand atomic styling, eliminating stylesheet bloat.
- Implemented performant vanilla JavaScript and CSS keyframes for custom interactive effects.

---

### Technical Details & Architecture

- **Island Architecture:** Leveraged selective hydration (`client:idle`, `client:visible`) to ensure zero unnecessary JavaScript runs on static content pages.
- **Svelte 5 Runes:** Utilized explicit `$state` and `$derived` primitives for state management in modal popups and filter systems.
- **Utility-First Styling:** Configured UnoCSS rules to output minimal, purged CSS bundles on build.
- **Responsive Layout:** Engineered responsive layouts optimized for all viewport sizes from mobile to ultra-wide displays.

---

### Challenges & Learnings

- **Partial Hydration Strategy:** Finding the balance between static HTML rendering and dynamic Svelte island hydration required understanding client directives (`client:idle` vs. `client:visible`).
- **Svelte 5 Rune Paradigms:** Transitioning to Svelte 5's new reactivity model deepened my understanding of fine-grained reactive dependency graphs.
- **User-Centric Design:** Learned to balance creative visual effects (glitch and CRT styling) with readability, accessibility, and smooth performance.

---

### Key Takeaways & Results

- **Blazing Fast Performance:** Achieved top-tier Lighthouse performance with instant sub-second page loads and zero layout shift.
- **Lean Asset Footprint:** Minimized total stylesheet size using UnoCSS on-demand utility generation.
- **Scalable Content Architecture:** Easily extensible structure allowing new projects and devlogs to be published seamlessly via Markdown/MDX.
